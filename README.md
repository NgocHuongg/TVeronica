Limitations. Owing to technical constraints on our side, concurrent execution of the complete test suite alongside Windows real-time protection was not feasible during this assessment. Real-time scanning interfered with the test workflow by removing staged artifacts prior to execution, and, as a workaround, portions of the kill chain were validated independently - with benign probe components standing in for operational payloads - instead of being exercised end-to-end in a single uninterrupted run. We acknowledge this as a methodological limitation of the current lab setup; future iterations will address it by isolating detonation in a dedicated virtual machine with protection settings fully under our control, and by automating artifact staging to minimize the window between generation and execution.
